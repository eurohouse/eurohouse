## Preamble

## Web Desktop Environment & Cultural Archive

An elegant *web desktop* environment that blends classical European cultural codes with modern web technologies. With Eurohouse, you carry your curated workspace everywhere: all files, user data, and personal settings remain under your control. The app features high‑quality *dynamic wallpaper* collections and is designed to be a refined addition to any workspace.

## Overview

**Eurohouse** is an open‑source IT project featuring a browser‑based desktop‑style web application and associated curated content. Hosted on GitHub, GitLab, GitVerse, and other Git‑based repositories, it is distributed freely “as is”.

The app provides curated collections (wallpapers, digital music albums) and supports integration of third‑party content (e.g., backgrounds, music) placed in the server’s working directory via Git.

Conceptually, Eurohouse synthesizes the following elements of the classical European cultural code:

- **Scientific method** (*methodus scientifica*) — structured reasoning and reproducible workflows.
- **Academic rigor** (*accuratio academica*) — clear taxonomy, metadata, and versioned content.
- **Historical accuracy** (*veritas historica*) — curated sources and contextual annotations.
- **Evidence‑based approach** (*medicina testimoniis probata* as a broader principle of evidence) — reliance on verifiable data and transparent provenance.
- **Christian values** (*fides, spes, caritas*) — ethical framing and human‑centered design.
- **Free will** (*liberum arbitrium*) — maximum user control over data, appearance, and behavior.
- **High culture** (*cultura sublimis*) — aesthetic coherence, language precision, and curated cultural references.

These elements together form a cultural code reflecting classical Europe and its civilizational branches—including Russia, the United States, Latin America, and others.

Technically, Eurohouse functions as an *online reference*, *digital archive*, and *micro‑museum*, accessible from any internet‑connected device. It is not a feature film or video game, but a tool for managing and personalizing content subscriptions within a structured, desktop‑like interface.

## Key Features

### Customizable Web Desktop Environment

- Full visual customization: styles, icon sets, fonts, sound effects, CSS colors, and animations.
- Built‑in *command palette* for rapid configuration of profile data, settings, and content limits (by package names).
- Integrated tools for mathematical reasoning:
  - *Terminal*: evaluate arithmetic, equations with multiple variables, and operations on sets/arrays (numbers and strings).
  - *Calculator*: classic interface for straightforward computations.

### Multifunctional Main Menu

- Multiple view modes: thumbnails, icons, and list.
- Configurable menu entries as dynamic sets of actions.

![Photorealistic English Village](https://github.com/eurohouse/baron/blob/main/baron.000.16.png?raw=true)

### Wallpaper Engine with Time‑Based Logic

- Switch between wallpaper collections and series via a top dropdown menu.
- Toggle visibility of the workspace using *Power*‑style controls.
- Support for custom backgrounds and daily wallpaper mode based on current time.

### Music Player with Subscription‑Aware Behavior

- *Albums*: packages of music files played within user’s content limits.
- *Playlists*: user‑managed collections with add/remove functionality.
- Shuffle/repeat modes when no playlist is defined.

### Content with Contextual Metadata

Each background links to an attached article stored in JSON files within the wallpaper collections. Articles include multilingual metadata: titles, texts, avatar icons, country, and, where relevant (e.g., for models), physical parameters (height, weight, body sizes, shoe size).

### Utility Modules

- **Sticky Notes**: manage personal text notes.
- **Messenger**: Twitter‑like messaging between users.
- **Artificial Intelligence**: integrated AI functions within the app.
